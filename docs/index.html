Abstract

Search engine snippets naturally decay as competitors aggressively optimize to steal clicks. This paper evaluates the most effective way to identify high-value, underperforming search snippets using real-world telemetry from the FlyRank ML Internship dataset. We compared a Random Forest Classifier trained on content features against a deterministic Baseline Rule sorting by “Wasted Impressions.” Our results show the simple Baseline Rule achieved a massive 0.94 Precision@50, severely outperforming the ML model (0.38 Precision@50 under a strict client-grouped split). We output a directional, human-reviewed action playbook to help SEO teams instantly identify pages bleeding traffic.

01

Problem Framing

Decision Supported: Helping SEO Content teams prioritize which pages need their <title> and <meta description> refreshed first.

Unit of Analysis: The page-level search snippet.

Why ML/Data helps: Manual auditing of millions of URLs is impossible. By surfacing the snippets bleeding the most clicks relative to their impressions, we can direct human editors strictly to the highest-ROI opportunities.

02

Data Safety

We used the March 2026 fact_content_daily_performance and dim_content partitions. We strictly excluded all PII and future-looking label-derived fields (like trend_direction and is_declining_label) to prevent data leakage.

03

Baseline Rule

We built a transparent, human-readable rule sorting pages by “Wasted Impressions”: impressions * (1.0 - ctr). This explicitly targets snippets that Google surfaces to thousands of users, but that users refuse to click.

04

Methodology

Target Label: A snippet is marked as “failing” if it receives >1,000 impressions but has a CTR < 0.01.

Model: Random Forest Classifier trained on text features (word_count, search_volume).

05

Evaluation & Audit

To prevent the model from memorizing client behavior, we utilized a strict GroupKFold split grouped by client_hash_id.

Error Analysis: The Random Forest severely over-indexed on word_count, falsely assuming massive pages automatically receive high impressions. The drop from random-split to grouped-split proved the ML model was merely memorizing clients.

06

Limitations

Search Intent Blindness: This pipeline does not know user search intent. It cannot tell the difference between a bad snippet and a “zero-click” informational query (e.g., “what is the capital of France”) where the user gets the answer directly on the Google search page without needing to click.

07

Ranked Recommendations (Action Playbook)

  • Action: REFRESH_SNIPPET for the top 50 flagged items.
  • Human Review Required: Editors must manually search the query to ensure it isn’t an informational “zero-click” query before rewriting the title.
  • The NO-GO List: Never hook this queue up to an LLM to automatically overwrite tags without human approval.
  • Monitoring: Track the 30-day post-refresh CTR. If it doesn’t lift by >10% against a control, review the logic.
